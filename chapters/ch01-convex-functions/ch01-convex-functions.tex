\section{Why Convexity Matters for AI}
\label{sec:ch01-why}

\begin{aibox}
  Linear regression, logistic regression, and SVMs have convex losses, so
  gradient descent finds the global minimum. Deep networks do not, and much
  of modern training practice exists to work around that.
\end{aibox}

\section{Functions: A Quick Refresher}
\label{sec:ch01-functions}
\subsection{Domain, Range, and Graphs}
\label{sec:ch01-domain-range}

A \emph{function} is a rule that assigns to each input exactly one output.
We write
\[
  f\colon A \to B
\]
to say that $f$ takes inputs from the set $A$ and produces outputs in the
set $B$. For example, $f\colon \R \to \R$, $f(x) = x^2$ takes any real
number and returns its square. The phrase ``exactly one'' matters: a rule
that could return two different values for the same input is not a
function.

\begin{definition}[Domain and range]
  \label{def:domain-range}
  Let $f\colon A \to B$.
  \begin{itemize}
    \item The \emph{domain} of $f$, written $\dom f$, is the set $A$ of
      allowed inputs.
    \item The \emph{range} (or \emph{image}) of $f$ is the set of outputs
      that actually occur:
      \[
        \operatorname{range} f = \{\, f(x) : x \in \dom f \,\}.
      \]
  \end{itemize}
\end{definition}

The range can be smaller than the set $B$ we wrote down. For
$f(x) = x^2$ on $\R$, every real number is an allowed input, but the range
is only $[0, \infty)$, because no real number squares to a negative value.

When a function is given by a formula with no domain stated, we take its
\emph{natural domain}: the largest set of inputs on which the formula makes
sense. The natural domain of $\log x$ is $(0, \infty)$, that of $\sqrt{x}$
is $[0, \infty)$, and that of $1/x$ is $\R \setminus \{0\}$.
\Cref{tab:ch01-domain-range} lists the domain and range of several
functions that come up repeatedly in this book.

\begin{table}[ht]
  \centering
  \caption{Domains and ranges of some common functions.}
  \label{tab:ch01-domain-range}
  \begin{tabular}{@{}lll@{}}
    \toprule
    Function & Domain & Range \\
    \midrule
    $x^2$ & $\R$ & $[0, \infty)$ \\
    $e^x$ & $\R$ & $(0, \infty)$ \\
    $\log x$ & $(0, \infty)$ & $\R$ \\

    \bottomrule
  \end{tabular}
\end{table}

Notice that $e^x$ and $\log x$ swap domain and range. This is no accident:
each undoes the other, so the outputs of one are exactly the allowed inputs
of the other.

\begin{aibox}
  Domains and ranges are design decisions in machine learning. A binary
  classifier ends in a sigmoid because its range $(0,1)$ is exactly where
  probabilities live. The cross-entropy loss $-\log p$ is defined only for
  $p > 0$, so a model that assigns probability $0$ to the correct label
  produces an infinite loss. This is why frameworks compute the loss from
  the raw scores (logits) rather than from probabilities.
\end{aibox}

The last point is easy to see in code. In exact arithmetic the sigmoid
never reaches $0$ or $1$, but floating-point numbers have limited
precision, so for large inputs it rounds to the endpoints, and the
logarithm then receives an input outside its domain:

\begin{lstlisting}
import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

sigmoid(np.array([-800.0, 0.0, 40.0]))  # array([0. , 0.5, 1. ])
np.log(sigmoid(-800.0))                 # -inf
np.log(-1.0)                            # nan
\end{lstlisting}

\paragraph{Functions of several variables.}
Inputs need not be single numbers. A function $f\colon \R^n \to \R$ takes a
vector $\vect{x} = (x_1, \dots, x_n)$ and returns a number, for example
\[
  f(\vect{x}) = x_1^2 + x_2^2 + \dots + x_n^2.
\]
The most important function in machine learning has this form: the
\emph{loss} $L\colon \R^d \to \R$, which maps a vector of model parameters
$\vect{\theta}$ to a single number measuring how badly the model fits the
data. Training a model means searching the domain $\R^d$ for a point where
$L$ is small, and for a large neural network $d$ is in the billions.

Domains of vector functions can be restricted too. A probability
distribution over $n$ outcomes is a vector in the \emph{probability simplex}
\[
  \Delta_n = \Bigl\{\, \vect{p} \in \R^n : p_i \ge 0 \text{ for all } i,\
  \textstyle\sum_{i=1}^n p_i = 1 \,\Bigr\},
\]
so functions of distributions, such as entropy, have $\Delta_n$ as their
domain. Likewise, the softmax function, which turns a vector of logits into
probabilities, has domain $\R^n$ and range inside $\Delta_n$.

\paragraph{Graphs.}
The \emph{graph} of a function collects every input together with its
output:
\[
  \operatorname{graph} f = \{\, (x, f(x)) : x \in \dom f \,\}.
\]
For $f\colon \R \to \R$, the graph is a curve in the plane. The domain is
the part of the horizontal axis the curve sits over, and the range is the
part of the vertical axis it covers. Because each input has exactly one
output, every vertical line meets the graph at most once.
\Cref{fig:ch01-graphs} shows three examples.

For $f\colon \R^2 \to \R$, the graph is a surface in three dimensions, like
the bowl in \Cref{fig:ch01-graphs}(c). For $f\colon \R^n \to \R$ with
$n > 2$, the graph lives in $\R^{n+1}$ and can no longer be drawn, but the
picture still guides intuition. When people speak of the \emph{loss
landscape} of a neural network, they mean the graph of its loss function:
a surface over parameter space whose valleys are good models. Much of this
chapter is about which shapes of landscape make the lowest valley easy to
find.

\begin{remark}
  The definition of convexity (\Cref{def:convex}) places a condition on the
  domain itself: $\dom f$ must be a \emph{convex set}, meaning that it
  contains the straight line segment between any two of its points. On the
  real line, the convex sets are the intervals. Domains, in other words, are not
  bookkeeping; they are part of what makes a function convex or not.
\end{remark}

\subsection{Functions You Will See Everywhere in AI}
\label{sec:ch01-ai-functions}

A neural network is assembled from a small number of building blocks.
Most of the work is done by linear maps, which multiply inputs by weights
and add them up. Between those maps sit a few fixed nonlinear functions
that turn raw scores into decisions, probabilities, or features. This
section introduces four of them: the sign function, the sigmoid, the
rectified linear unit (ReLU), and the softmax. The first three take one
number and return one number, and \Cref{fig:ch01-activations} shows them
side by side. The softmax takes a whole vector of scores.

\paragraph{The sign function.}
The simplest way to turn a score into a decision is to look at its sign:
\[
  \operatorname{sign} x =
  \begin{cases}
    1 & x > 0, \\
    0 & x = 0, \\
    -1 & x < 0.
  \end{cases}
\]
Its domain is $\R$ and its range is the three-point set $\{-1, 0, 1\}$.
The \emph{perceptron}, one of the earliest learning algorithms, is a sign
function applied to a weighted sum of the inputs: given a feature vector
$\vect{x}$, weights $\vect{w}$, and an offset $b$, it predicts the class
\[
  \hat{y} = \operatorname{sign}(\vect{w}^\top \vect{x} + b).
\]
The sign function also appears inside optimizers. The Lion optimizer, for
example, moves each parameter by a fixed step size in the direction given
by the sign of its update.

The graph in \Cref{fig:ch01-activations}(a) shows why the sign function is
rarely used inside the layers of a trained network. It is flat everywhere
except at $0$, where it jumps. A small change to the weights almost never
changes the output, so the function gives no signal about which direction
would improve the model. Learning by gradient descent, the subject of
\Cref{chap:ch08}, needs functions whose outputs respond smoothly to their
inputs. The next function is the standard way to get one.

\paragraph{The sigmoid.}
The \emph{sigmoid}, also called the \emph{logistic function}, is
\[
  \sigma(x) = \frac{1}{1 + e^{-x}}.
\]
Its domain is $\R$ and its range is $(0, 1)$. Large positive inputs give
outputs close to $1$, large negative inputs give outputs close to $0$, and
$\sigma(0) = \tfrac12$. The graph in \Cref{fig:ch01-activations}(b) is an
S-shaped curve that looks like a sign function with the jump smoothed out.
The two are closely related:
\[
  2\sigma(x) - 1 = \tanh\!\left(\frac{x}{2}\right),
\]
and as $k \to \infty$, the steeper sigmoid $\sigma(kx)$ approaches a step
from $0$ to $1$. Another useful property follows directly from the
definition:
\[
  \sigma(-x) = 1 - \sigma(x).
\]

Because its outputs lie strictly between $0$ and $1$, the sigmoid turns any
real-valued score into a probability. \emph{Logistic regression} models the
probability that an example belongs to the positive class as
\[
  P(y = 1 \mid \vect{x}) = \sigma(\vect{w}^\top \vect{x} + b),
\]
and by the symmetry above, $P(y = 0 \mid \vect{x}) = \sigma(-(\vect{w}^\top
\vect{x} + b))$. Inverting the sigmoid gives the \emph{logit} function
$\sigma^{-1}(p) = \log\bigl(p / (1 - p)\bigr)$, which maps a probability
back to a score. This is why the raw scores a model produces before any
sigmoid or softmax are called \emph{logits}.

\paragraph{The rectified linear unit.}
The \emph{ReLU} keeps positive inputs and replaces negative ones with zero:
\[
  \operatorname{ReLU}(x) = \max(0, x).
\]
Its domain is $\R$ and its range is $[0, \infty)$. The graph in
\Cref{fig:ch01-activations}(c) consists of two straight pieces that meet at
a corner at the origin. ReLU is the default activation function in the
hidden layers of deep networks, for two reasons. It is cheap to compute,
and for positive inputs its slope is always $1$, whereas the sigmoid
flattens out at both ends. In a deep network, signals must pass through
many layers, and flat regions in each layer combine to stop learning.
ReLU's flat region on the negative side has the same effect on a single
unit: a unit whose input is negative for every training example outputs
$0$ for all of them and stops learning, a failure known as a \emph{dead
neuron}. Smooth variants such as GELU, used in most transformers, bend the
corner slightly to reduce this problem.

ReLU is also our first example of a convex function that is not smooth.
It is convex because it is the maximum of two linear functions, $0$ and
$x$.

\paragraph{The softmax.}
A classifier with $n$ classes produces a vector of $n$ logits
$\vect{z} = (z_1, \dots, z_n)$, one score per class, and needs to turn them
into a probability distribution. The \emph{softmax} does this:
\[
  \operatorname{softmax}(\vect{z})_i = \frac{e^{z_i}}{\sum_{j=1}^n e^{z_j}},
  \qquad i = 1, \dots, n.
\]
Exponentiating makes every entry positive, and dividing by the sum makes
the entries add up to $1$. The softmax is therefore a function from $\R^n$
into the probability simplex $\Delta_n$ of \Cref{sec:ch01-domain-range}.
Its outputs are never exactly $0$, so its range is the part of $\Delta_n$
where every $p_i > 0$. Larger logits get larger probabilities, and the
ordering of the classes is preserved.

Three properties of the softmax come up repeatedly.
\begin{itemize}
  \item \emph{Shift invariance.} Adding the same constant $c$ to every
    logit does not change the output, because the factor $e^c$ cancels
    between numerator and denominator:
    $\operatorname{softmax}(\vect{z} + c\vect{1}) =
    \operatorname{softmax}(\vect{z})$. Only differences between logits
    matter.
  \item \emph{It generalizes the sigmoid.} With two classes,
    \[
      \operatorname{softmax}(z_1, z_2)_1 = \frac{e^{z_1}}{e^{z_1} + e^{z_2}}
      = \frac{1}{1 + e^{-(z_1 - z_2)}} = \sigma(z_1 - z_2).
    \]
  \item \emph{Temperature.} Dividing the logits by a temperature $T > 0$
    before applying the softmax controls how peaked the result is. As
    $T \to 0$, the output approaches a one-hot vector with all its mass on
    the largest logit, the same answer as $\argmax$. As $T \to \infty$, it
    approaches the uniform distribution. \Cref{fig:ch01-softmax} shows an
    example. The name ``softmax'' comes from this behavior: it is a soft,
    smooth version of picking the maximum.
\end{itemize}

\begin{aibox}
  The softmax appears in three central places. It is the final layer of
  almost every classifier, turning logits into class probabilities. It is
  the heart of the attention mechanism in transformers
  (\Cref{chap:ch10}), where it turns similarity scores into weights that
  sum to one. And when a language model generates text, it samples each
  next token from a softmax over its vocabulary; the ``temperature''
  setting in a chatbot is exactly the $T$ above.
\end{aibox}

The shift invariance has a practical use. Computing $e^{z_i}$ directly
overflows for logits as small as $1000$, but subtracting the largest logit
first leaves the answer unchanged and keeps every exponent at most $0$.
Every deep learning library computes the softmax this way:

\begin{lstlisting}
import numpy as np

def softmax_naive(z):
    e = np.exp(z)
    return e / e.sum()

def softmax(z):
    e = np.exp(z - z.max())   # shift so the largest logit is 0
    return e / e.sum()

z = np.array([1000.0, 999.0, 998.0])
softmax_naive(z)   # array([nan, nan, nan])  (exp overflows to inf)
softmax(z)         # about [0.665, 0.245, 0.090]
\end{lstlisting}

\section{Definition of a Convex Function}
\label{sec:ch01-definition}

Informally, a convex function is shaped like a bowl: it curves upward
everywhere and has no false bottoms. The definition turns this picture
into an inequality about averages.

\begin{definition}[Convex function]
  \label{def:convex}
  A function $f\colon \dom f \to \R$, where $\dom f$ is a convex set, is
  \emph{convex} if for all $x, y \in \dom f$ and all $\theta \in [0,1]$,
  \begin{equation}
    f\bigl(\theta x + (1-\theta) y\bigr) \le \theta f(x) + (1-\theta) f(y).
    \label{eq:convex}
  \end{equation}
\end{definition}

The number $\theta x + (1 - \theta) y$ is a weighted average of the two
inputs: it equals $y$ when $\theta = 0$, $x$ when $\theta = 1$, and lies
between them otherwise. The left side of~\eqref{eq:convex} evaluates $f$ at
this averaged input. The right side takes the same weighted average of the
two outputs. So the definition says:
\begin{center}
  \emph{$f$ of an average is at most the average of $f$.}
\end{center}
The requirement that $\dom f$ be convex guarantees that the averaged input
is still in the domain, so the left side makes sense. The definition reads
the same for $f\colon \R^n \to \R$, with $x$ and $y$ vectors; loss
functions of many parameters are judged by exactly this inequality.

As a quick check, take $f(x) = x^2$, $x = -1$, $y = 3$, and
$\theta = \tfrac12$. The averaged input is $1$, so the left side is
$f(1) = 1$, while the right side is $\tfrac12 \bigl(f(-1) + f(3)\bigr) =
\tfrac12 (1 + 9) = 5$. Indeed $1 \le 5$. One check proves nothing, of
course; convexity requires the inequality for \emph{every} choice of $x$,
$y$, and $\theta$. The following examples prove it in general.
\Cref{fig:ch01-convex-examples} shows their graphs.

\begin{example}[Affine functions]
  \label{ex:ch01-affine}
  Let $f(x) = ax + b$. Since $\theta b + (1 - \theta) b = b$,
  \[
    f\bigl(\theta x + (1 - \theta) y\bigr)
    = a\bigl(\theta x + (1 - \theta) y\bigr) + b
    = \theta (a x + b) + (1 - \theta)(a y + b)
    = \theta f(x) + (1 - \theta) f(y).
  \]
  The inequality holds with equality, so every affine function is convex.
  The same computation works for $f(\vect{x}) = \vect{w}^\top \vect{x} + b$
  on $\R^n$, the score of a linear model.
\end{example}

\begin{example}[The square]
  \label{ex:ch01-square}
  Let $f(x) = x^2$. Subtract the left side of~\eqref{eq:convex} from the
  right side and expand:
  \begin{align*}
    \theta x^2 + (1 - \theta) y^2 - \bigl(\theta x + (1 - \theta) y\bigr)^2
    &= \theta (1 - \theta) x^2 + \theta (1 - \theta) y^2
       - 2 \theta (1 - \theta) x y \\
    &= \theta (1 - \theta) (x - y)^2 .
  \end{align*}
  Both $\theta (1 - \theta)$ and $(x - y)^2$ are nonnegative, so the
  difference is nonnegative and $x^2$ is convex. This is the reason the
  squared error $(y - \hat{y})^2$ is a convex loss.
\end{example}

\begin{example}[Absolute value]
  \label{ex:ch01-abs}
  Let $f(x) = |x|$. By the triangle inequality, and because $\theta$ and
  $1 - \theta$ are nonnegative,
  \[
    \bigl|\theta x + (1 - \theta) y\bigr|
    \le |\theta x| + |(1 - \theta) y|
    = \theta |x| + (1 - \theta) |y|.
  \]
  So $|x|$ is convex, despite the corner at $0$. It is the building block of
  the $L_1$ penalty $\sum_i |w_i|$.
\end{example}

\begin{example}[Exponential]
  \label{ex:ch01-exp}
  The function $e^x$ is convex. A direct algebraic proof is awkward, so
  we only test one case: with $x = 0$, $y = 2$, and $\theta = \tfrac12$, the left
  side is $e^1 \approx 2.72$ and the right side is $\tfrac12(1 + e^2)
  \approx 4.19$.
\end{example}

\begin{example}[A function that is not convex]
  \label{ex:ch01-cubic}
  To show a function is \emph{not} convex, one failure is enough. Let
  $f(x) = x^3$, $x = -2$, $y = 0$, and $\theta = \tfrac12$. The left side is
  $f(-1) = -1$, and the right side is $\tfrac12(-8 + 0) = -4$. Since
  $-1 > -4$, inequality~\eqref{eq:convex} fails. Restricted to the domain
  $[0, \infty)$, however, $x^3$ is convex; as the remark in
  \Cref{sec:ch01-domain-range} warned, the domain is part of the question.
\end{example}

\subsection{Geometric Picture: The Chord Lies Above the Graph}
\label{sec:ch01-chord}

Inequality~\eqref{eq:convex} has a picture. For $f\colon \R \to \R$, mark
two points on the graph, $(x, f(x))$ and $(y, f(y))$, and join them with a
straight line segment, called a \emph{chord}. As $\theta$ runs from $0$ to
$1$, the point
\[
  \bigl(\theta x + (1 - \theta) y,\ \theta f(x) + (1 - \theta) f(y)\bigr)
\]
runs along the chord from one end to the other, because both coordinates
are the same weighted average. At the input
$z = \theta x + (1 - \theta) y$, the right side of~\eqref{eq:convex} is
therefore the height of the chord, and the left side, $f(z)$, is the
height of the graph (\Cref{fig:ch01-chord}). The definition says:
\begin{center}
  \emph{$f$ is convex exactly when every chord lies on or above the graph.}
\end{center}
This is the test to apply by eye. In \Cref{fig:ch01-convex-examples}, every
chord of $x^2$, $|x|$, and $e^x$ stays above the graph, while for $x^3$ a
chord over the negative numbers dips below it.

\subsection{Strict and Strong Convexity}
\label{sec:ch01-strict-strong}

Convexity allows the chord to touch the graph along its whole length; an
affine function satisfies~\eqref{eq:convex} with equality. Two stronger
conditions rule this out.

\begin{definition}[Strictly convex]
  \label{def:strictly-convex}
  A function $f$ is \emph{strictly convex} if
  \[
    f\bigl(\theta x + (1 - \theta) y\bigr) < \theta f(x) + (1 - \theta) f(y)
  \]
  for all $x \ne y$ in $\dom f$ and all $\theta \in (0, 1)$.
\end{definition}

Geometrically, every chord lies strictly above the graph except at its
endpoints: the graph has no straight pieces. By \Cref{ex:ch01-square}, the
gap for $x^2$ is $\theta (1 - \theta)(x - y)^2$, which is positive when
$x \ne y$ and $0 < \theta < 1$, so $x^2$ is strictly convex. So is $e^x$.
Affine functions are not, and neither is $|x|$: for two positive inputs the
chord lies along the graph (\Cref{fig:ch01-convex-examples}(b)).

Strict convexity matters for learning because it pins down the answer.

\begin{proposition}
  \label{prop:ch01-unique-min}
  A strictly convex function has at most one minimizer.
\end{proposition}

\begin{proof}
  Suppose $x \ne y$ are both minimizers, with $f(x) = f(y) = m$, the
  smallest value of $f$. Strict convexity at $\theta = \tfrac12$ gives
  $f\bigl(\tfrac12 (x + y)\bigr) < \tfrac12 m + \tfrac12 m = m$, a value
  below the minimum, which is impossible.
\end{proof}

Strict convexity can still be weak in practice. The gap between chord and
graph for $e^x$ is positive, but over very negative inputs the graph is
nearly flat, and so is every chord there. Strong convexity asks for a gap
that does not fade.

\begin{definition}[Strongly convex]
  \label{def:strongly-convex}
  Let $m > 0$. A function $f$ is \emph{$m$-strongly convex} if for all
  $x, y \in \dom f$ and all $\theta \in [0, 1]$,
  \[
    f\bigl(\theta x + (1 - \theta) y\bigr)
    \le \theta f(x) + (1 - \theta) f(y)
      - \frac{m}{2}\, \theta (1 - \theta) (x - y)^2 .
  \]
  For $f\colon \R^n \to \R$, replace $(x - y)^2$ by
  $\|\vect{x} - \vect{y}\|^2$.
\end{definition}

The chord now sits above the graph by at least a fixed multiple of the
squared distance between the endpoints, everywhere. \Cref{ex:ch01-square}
shows that $x^2$ meets this with $m = 2$, and in the same way
$\tfrac{m}{2} x^2$ is $m$-strongly convex. The function $e^x$ is strictly
but not strongly convex, because its gap shrinks to zero as the inputs
move left. \Cref{tab:ch01-strict-strong} sorts the examples; each column
implies the one before it.

\begin{aibox}
  Adding the $L_2$ penalty $\tfrac{\lambda}{2} \|\vect{w}\|^2$ to a convex
  loss makes the total $\lambda$-strongly convex, because the penalty
  contributes its own gap of $\tfrac{\lambda}{2} \theta (1 - \theta)
  \|\vect{x} - \vect{y}\|^2$. This is why ridge regression always has a
  single best solution, and, as \Cref{chap:ch08} shows, why gradient
  descent converges quickly on it.
\end{aibox}

\subsection{Concave Functions}
\label{sec:ch01-concave}

Flip a convex function upside down and you get a concave one.

\begin{definition}[Concave function]
  \label{def:concave}
  A function $f$ is \emph{concave} if $-f$ is convex. Equivalently, for all
  $x, y \in \dom f$ and all $\theta \in [0, 1]$,
  \[
    f\bigl(\theta x + (1 - \theta) y\bigr) \ge \theta f(x) + (1 - \theta) f(y).
  \]
\end{definition}

The inequality is reversed: $f$ of an average is \emph{at least} the
average of $f$, and every chord lies on or below the graph
(\Cref{fig:ch01-concave}). A concave function is a dome rather than a bowl.
Standard examples are $\log x$ on $(0, \infty)$, $\sqrt{x}$ on
$[0, \infty)$, and $-x^2$ on $\R$. For instance, with $x = 1$, $y = 9$, and
$\theta = \tfrac12$, we get $\sqrt{5} \approx 2.24 \ge \tfrac12 (1 + 3) =
2$. Affine functions are both convex and concave, and they are the only
functions that are both. Most functions, such as $x^3$ and $\sin x$, are
neither.

Concavity is the natural notion for quantities we want to make
\emph{large}. Maximizing a concave function $f$ is the same problem as
minimizing the convex function $-f$, so everything this chapter says about
minimizing convex functions applies. Machine learning uses this constantly.
The log-likelihood of logistic regression is concave in the weights, and
training maximizes it; in practice, libraries minimize its negative, the
cross-entropy loss, which is convex.

\subsection{The Epigraph View}
\label{sec:ch01-epigraph}

There is a second way to see convexity, which turns a statement about a
function into a statement about a set.

\begin{definition}[Epigraph]
  \label{def:epigraph}
  The \emph{epigraph} of $f\colon \dom f \to \R$ is the set of points on or
  above its graph:
  \[
    \epi f = \{\, (x, t) : x \in \dom f,\ t \ge f(x) \,\}.
  \]
\end{definition}

For $f\colon \R \to \R$, the epigraph is a region of the plane: the graph
together with everything above it (\Cref{fig:ch01-epigraph}). For
$f\colon \R^n \to \R$, it is a region of $\R^{n+1}$.

\begin{proposition}
  \label{prop:ch01-epigraph}
  A function $f$ is convex if and only if $\epi f$ is a convex set.
\end{proposition}

\begin{proof}
  Suppose $f$ is convex, and take two points $(x, s)$ and $(y, t)$ of
  $\epi f$, so that $s \ge f(x)$ and $t \ge f(y)$. For $\theta \in [0, 1]$,
  \[
    \theta s + (1 - \theta) t
    \ge \theta f(x) + (1 - \theta) f(y)
    \ge f\bigl(\theta x + (1 - \theta) y\bigr),
  \]
  so the point $\theta (x, s) + (1 - \theta)(y, t)$ is in $\epi f$.
  Conversely, if $\epi f$ is convex, apply its convexity to the points
  $(x, f(x))$ and $(y, f(y))$, which lie in $\epi f$. Their weighted
  average $\bigl(\theta x + (1 - \theta) y,\ \theta f(x) + (1 - \theta)
  f(y)\bigr)$ is in $\epi f$, which says exactly
  that~\eqref{eq:convex} holds.
\end{proof}

In the chord picture, a segment between two points of the epigraph is a
chord lifted upward, and it stays in the epigraph precisely when chords
stay above the graph. \Cref{fig:ch01-epigraph}(b) shows how $x^3$ fails:
its epigraph has a dent, and a segment between two of its points passes
outside.

The epigraph view makes some facts almost free. A point lies above the
graph of $\max(f, g)$ exactly when it lies above both graphs, so
\[
  \epi \max(f, g) = \epi f \cap \epi g.
\]
If two sets each contain the segment between any two of their points, so
does their intersection. Hence the maximum of two convex functions is
convex. Taking $f(x) = 0$ and $g(x) = x$, both affine, shows once more that
$\operatorname{ReLU}(x) = \max(0, x)$ is convex.

\subsection{Why Convex Problems Are Easy: Local Minima Are Global}
\label{sec:ch01-local-global}

Training a model means minimizing a loss. The algorithms that do this,
gradient descent and its relatives, are \emph{local}: at each step they look
only at the shape of the function near the current point and move
downhill. When they stop, all they can promise is that no nearby point is
lower. Whether that is good enough depends on the shape of the whole
function, and this is where convexity pays off.

\begin{definition}[Global and local minimizers]
  \label{def:minimizers}
  Let $f\colon \dom f \to \R$ and $x^\star \in \dom f$.
  \begin{itemize}
    \item $x^\star$ is a \emph{global minimizer} if $f(x^\star) \le f(x)$
      for all $x \in \dom f$.
    \item $x^\star$ is a \emph{local minimizer} if there is a radius
      $r > 0$ such that $f(x^\star) \le f(x)$ for all $x \in \dom f$ with
      $|x - x^\star| \le r$. For $f\colon \R^n \to \R$, use
      $\|\vect{x} - \vect{x}^\star\|$ in place of $|x - x^\star|$.
  \end{itemize}
\end{definition}

Every global minimizer is local, but not the other way around. The
function $f(x) = x^4 - 4x^2 + x$ in \Cref{fig:ch01-local-global}(b) has two
valleys. The bottom of the left one, near $x = -1.47$, is the global
minimizer, with $f \approx -5.44$. The bottom of the right one, near
$x = 1.35$, is only a local minimizer, with $f \approx -2.62$. An algorithm
that walks downhill from $x = 2$ settles in the right valley and has no way
of knowing that a better one exists. For convex functions this cannot
happen.

\begin{theorem}
  \label{thm:ch01-local-global}
  If $f$ is convex, every local minimizer of $f$ is a global minimizer.
\end{theorem}

\begin{proof}
  Let $x^\star$ be a local minimizer with radius $r$, and suppose, to reach
  a contradiction, that some $y$ has $f(y) < f(x^\star)$. Walk from
  $x^\star$ toward $y$: for $\theta \in (0, 1]$, let
  $z = \theta y + (1 - \theta) x^\star$. By convexity,
  \[
    f(z) \le \theta f(y) + (1 - \theta) f(x^\star)
    < \theta f(x^\star) + (1 - \theta) f(x^\star) = f(x^\star).
  \]
  So every point on the segment from $x^\star$ to $y$, other than
  $x^\star$ itself, is strictly lower than $x^\star$. The distance from $z$
  to $x^\star$ is $\theta |y - x^\star|$, so choosing $\theta$ small enough
  puts $z$ within distance $r$ of $x^\star$. That contradicts $x^\star$
  being a local minimizer. Hence no such $y$ exists.
\end{proof}

The proof is the chord picture again. If a lower point $y$ existed, the
chord from $x^\star$ to $y$ would slope downward, and since the graph lies
on or below the chord, the graph would also go down immediately next to
$x^\star$. A convex function has no isolated valleys: from any point that is
not a global minimizer, some direction leads downhill.

Two more facts follow quickly.
\begin{itemize}
  \item \emph{The minimizers form a convex set.} If $x$ and $y$ are both
    global minimizers with value $m$, then
    $f\bigl(\theta x + (1 - \theta) y\bigr) \le \theta m + (1 - \theta) m
    = m$, so every point between them is a minimizer too. A convex function
    can have a flat bottom (\Cref{fig:ch01-local-global}(a)), but it cannot
    have two separate ones.
  \item \emph{Strict convexity gives uniqueness.} By
    \Cref{prop:ch01-unique-min}, a strictly convex function has at most one
    minimizer, so the flat bottom shrinks to a single point.
\end{itemize}

    minimizer (green) and a worse local minimizer (red). Walking downhill
    from $x = 2$ (arrow) ends in the local one.}
  \label{fig:ch01-local-global}
\end{figure}

The difference shows up as soon as we run an optimizer. The code below
applies gradient descent, which repeatedly takes a small step against the
slope (the derivative, \Cref{chap:ch02}), to a convex function and to the
non-convex function above, from three starting points:

\begin{lstlisting}
def gradient_descent(slope, x, lr=0.01, steps=1000):
    for _ in range(steps):
        x = x - lr * slope(x)     # step downhill
    return x

convex_slope    = lambda x: 2 * (x - 1)            # f(x) = (x - 1)^2
nonconvex_slope = lambda x: 4 * x**3 - 8 * x + 1   # f(x) = x^4 - 4x^2 + x

for x0 in [-2.0, 0.5, 2.0]:
    print(x0, gradient_descent(convex_slope, x0),
              gradient_descent(nonconvex_slope, x0))
# -2.0  1.0  -1.473   (global minimum)
#  0.5  1.0   1.347   (stuck in the local minimum)
#  2.0  1.0   1.347   (stuck in the local minimum)
\end{lstlisting}

On the convex function, every start reaches the same answer. On the
non-convex one, the answer depends on where we begin, and two of the three
runs end in the worse valley.

\begin{aibox}
  This theorem is the reason classical models are reliable. Linear
  regression, logistic regression, and SVMs have convex losses, so any
  solver that reaches a local minimum has found the best possible model,
  regardless of initialization. Deep network losses are not convex: two
  training runs with different random seeds end at different parameters,
  and nothing guarantees either is globally optimal. Remarkably, large
  networks still tend to reach local minima that are almost as good as
  the best, a phenomenon we return to in \Cref{chap:ch08,chap:ch09}.
\end{aibox}

\section{Summary}
\label{sec:ch01-summary}

\begin{itemize}
  \item A function is \emph{convex} if $f$ of a weighted average of inputs
    is at most the same weighted average of outputs,
    $f\bigl(\theta x + (1 - \theta) y\bigr) \le \theta f(x) + (1 - \theta) f(y)$.
    Geometrically, every chord lies on or above the graph.
  \item Affine functions, $x^2$, $|x|$, and $e^x$ are convex; $x^3$ is not.
    One failed instance of the inequality is enough to show a function is
    not convex.
  \item \emph{Strict} convexity rules out straight pieces and gives at most
    one minimizer. \emph{Strong} convexity guarantees a gap between chord
    and graph that grows with distance; adding an $L_2$ penalty creates it.
  \item A function is \emph{concave} if $-f$ is convex. Maximizing a
    concave function is the same as minimizing a convex one.
  \item $f$ is convex exactly when its epigraph is a convex set. Since
    $\epi \max(f, g) = \epi f \cap \epi g$, the maximum of convex
    functions, such as ReLU, is convex.
  \item For a convex function, every local minimizer is global. This is why
    convex models train reliably from any starting point, while deep
    networks, whose losses are not convex, do not come with that
    guarantee.
\end{itemize}

Boyd and Vandenberghe~\cite{boyd2004convex} is the standard reference for
going further with convex functions and convex optimization.
